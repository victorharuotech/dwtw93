O problema

Os dados estavam presos em PDFs antigos

O Liber 777 (1909) e o Sepher Sephiroth (1912) são dicionários de símbolos — mas só existem como PDFs com tabelas em duas colunas e o hebraico numa fonte antiga.

o PDF diz \yhla
a fonte inverte e troca as letras → אלהים

Extrair esse texto “do jeito comum” devolve colunas embaralhadas e letras sem sentido.

A solução

Um pipeline de dados de ponta a ponta

PDFcoordenadas de cada linha (Swift · PDFKit)
▼
Parserreconstrói o layout e decodifica a fonte (Python)
▼
Validaçãoguematria como checksum + correções revisadas
▼
SQLitemodelo EAV para as tábuas · índices · views
▼
FlaskAPI JSON · modo público configurável
▼
InterfaceJavaScript puro · módulos ES · SVG
O pulo do gato

A própria regra do domínio virou o teste

Cada letra hebraica tem um valor. No dicionário, cada palavra está sob o número que ela soma — então a soma valida a extração.

משיה = 353 ≠ 358 ⚠  erro do PDF
משיח = 358 ✓  corrigido
2.327verbetes validados
79erros do PDF corrigidos
3.890palavras reconferidas no site
77testes automatizados
O resultado

A Árvore da Vida, interativa

Dez esferas e vinte e dois caminhos em SVG, nas quatro escalas de cor do 777. Cada caminho abre suas correspondências e as cartas do Tarô ligadas a ele.
